# Aliphilip — Ali Philip's portfolio

**Live site:** [aliphilip05.github.io](https://aliphilip05.github.io/)

This repository contains the static portfolio published as Ali Philip's GitHub Pages homepage. It highlights selected astronomy research, software projects, coursework, and hackathon experiences. “Aliphilip” is the site's displayed name; the public address is currently the GitHub Pages URL above.

## Pages

| Page | What it contains |
| --- | --- |
| [`index.html`](index.html) | Homepage, selected projects, and an Events section with HackRU / Jot. Astrolings is listed as a prototype with no project link. |
| [`research.html`](research.html) | Notes on the multi-band CAS analysis, candidate sample, measurements, and limitations. |
| [`coursework.html`](coursework.html) | Coursework and independent project notes. |

[`styles.css`](styles.css) provides the responsive design, and [`site.js`](site.js) handles the mobile menu and footer year. The site uses plain HTML, CSS, and JavaScript; it has no build step or server-side application.

## Publishing

GitHub Pages publishes this repository's `main` branch from its root. Its root [`index.html`](index.html) is the homepage at `https://aliphilip05.github.io/`. The research and coursework pages are at `/research.html` and `/coursework.html`. Editing files locally changes only the checkout; pushing a commit to `main` updates the public site after GitHub Pages deploys it.

The [Casper CAS / E+A website](https://aliphilip05.github.io/Casper-Analysis-Of-E-Galaxies-/) is published separately from the [Casper project repository](https://github.com/AliPhilip05/Casper-Analysis-Of-E-Galaxies-). This portfolio links to that site and does not contain its dashboard or analysis code.
