# APhlip.org portfolio

This repository is the source for [Ali Philip’s public homepage](https://aliphilip05.github.io/). GitHub Pages serves `index.html` at the site root, with `research.html`, `coursework.html`, `styles.css`, and `site.js` alongside it. Changes pushed to `main` are published from this repository.

The [Casper CAS / E+A website](https://aliphilip05.github.io/Casper-Analysis-Of-E-Galaxies-/) is published independently from the [Casper project repository](https://github.com/AliPhilip05/Casper-Analysis-Of-E-Galaxies-). The portfolio links to that site; no Casper source files are stored here.
